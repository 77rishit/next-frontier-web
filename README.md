# TechFest Frontier

Create a highly immersive, visually spectacular landing page for TECHFEST, IIT BOMBAY.

This is a visual web-development challenge. The website must look like a premium technology festival experience, NOT like a generic college website, SaaS landing page, portfolio, or dashboard.

REFERENCE DIRECTION:

The official Techfest website uses a highly customized visual language with:

- cinematic full-screen backgrounds

- elaborate metallic/futuristic frames

- custom navigation UI

- large decorative typography

- floating side navigation

- themed event cards

- strong visual storytelling

- layered backgrounds

- fantasy/game-inspired interface elements

Use that LEVEL of visual richness and customization as inspiration, but DO NOT copy the official website's exact layout, assets, artwork, typography, or branding.

Our design direction should be ORIGINAL:

FUTURISTIC TECHNOLOGY × IIT BOMBAY × INDIAN INNOVATION.

IMPORTANT CONSTRAINT:

NO 3D ASSETS.

NO Three.js.

NO WebGL.

NO 3D models.

NO external 3D scenes.

Create depth using:

- CSS

- SVG

- gradients

- particles

- 2D images

- masks

- glow

- blur

- parallax

- layered elements

- animated borders

- typography.
